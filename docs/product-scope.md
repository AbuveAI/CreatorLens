# 首版产品范围

决策日期：2026-11-17。

## 用户和价值

用户是已经使用 Agent 的内容创作者。首个完整场景：提供一个参考账号，
获得有作品证据、评论线索、样本边界和创作启发的本地研究报告。

产品的主要价值是可追溯研究、语义审阅、可恢复流程和创作决策支持。
采集是研究入口；不以换一层采集命令作为全部产品价值。

## 首版能力（已实现本地链路，待真实场景验收）

1. Agent 根据仓库说明检查环境并引导用户配置自己的工作区。
2. 只通过 Spider_XHS 接口获取账号、作品、视频/图文、评论和来源信息。
3. 默认最近 10 条有效作品，去重和置顶归位；严格超过 20 分钟的视频排除并补位。
4. 视频按授权调用豆包 ASR；没有转写服务时显示缺失环节，不假装完成视频语义研究。
5. Agent 全文校订转写、实际逐图阅读，形成结构化研究及本地 Markdown 报告。
6. 明确采集覆盖、未知指标、评论缺口、推断边界及原始证据。
7. 检查点用于安全恢复；不得为续跑而重复付费提交。
8. 可选飞书清单交给Agent，通过用户自己的工具同步并回读，不影响本地报告完成状态。

## 首版不做

浏览器视觉采集或回退、其他采集底座、无人值守定时抓取、自动发布作品、私信、直播互动、
全平台支持承诺、预测爆款或保证流量。上游有某项能力不代表 CreatorLens 自动开放该能力。

## 后续扩展

抖音、视频号、B 站按独立接口适配器逐步接入。采集接口与通用研究分层，
先从真实需求提取公共结构，不提前建立空平台实现。
导入已有采集结果列为候选能力，首版是否纳入取决于契约和验收成本。

## 发布验收目标

干净环境中，Agent 仅凭公共说明可完成安装、配置、真实混合样本研究和本地报告。
须验证中断恢复、缺少 ASR/飞书配置时的明确提示、纯接口限制以及私人资料隔离。
新版本须独立验收，不继承旧目录的完成标签。
