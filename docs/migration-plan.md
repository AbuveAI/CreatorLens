## 实际发现

- 旧共享包导出函数明确包含浏览器下载脚本，不能将现有 ZIP 直接作为纯接口公开版本。
- 旧 session.py 使用源码根目录下的私人目录；旧 CLI 的临时文件与飞书锁也使用源码根目录。
- 旧混合采集遇图文会记录 pending_mixed_workflow 并停止，完整混合链仍待封装。
- 旧分析具备分类配置入口，但默认分类仍偏 AI 内容；应将通用模板与具体赛道分离。
- 旧报告固定输出视频数量和小红书证据链接，尚不是跨媒体、跨平台报告。
- 旧 doctor 包含另一套下载器，不能作为新工程纯接口验收依据。
- 旧本机依赖目录没有 Git 元数据，不能仅凭历史文档中的提交号证明当前源码版本。
