# 维护与发布

公共核心只有一份。通用修复在本仓库开发，用外置私人工作区验证；私人偏好留在 profiles/。
旧工程只在过渡期保留必要维护，新功能逐步集中到本仓库，不长期双向同步整目录。

一个可审阅的修复或功能通过测试后按功能提交。正式发布使用版本标签与更新说明；
课程和演示记录适用版本，不直接依赖不断变化的开发分支。

正式公开前检查：

1. 第一版混合样本端到端与恢复验收通过，说明实际支持的操作系统。
2. 只打包公共白名单；检查文件内容、Git 历史、测试样本和日志是否含私人信息。
3. 不携带第三方源码、安装环境、会话、密钥、本机路径、真实素材或报告。
4. 保留自有代码MIT许可证，保留第三方许可、来源和版本记录；不把联系作者设为开发步骤，不宣称已获额外授权或保证可自由商用。
5. 版本声明与实际能力一致。清楚区分依赖存在、登录有效、采集成功、语义审阅和最终验收。
6. 迁移任务结构时提供迁移方案或明确不兼容，不直接改写历史批次。

公共仓库为 https://github.com/AbuveAI/CreatorLens 。首版以Alpha源码提供，未配置自动发布。

## 上游依赖升级

当前setup锁定单一上游提交，重复安装不会git pull。要升级时先在独立测试工作区检出候选版本，核对接口形状与必要依赖，运行离线回归和授权的真实样本；通过后更新setup中的固定提交与版本说明。现有用户选择升级时保留原环境及旧任务，优先新建工作区。手工配置候选源码须显式dependency-lock；--replace只确认当前指纹，不会证明兼容。已经开始的批次绑定runtime指纹，不在批次中途替换上游。

setup失败后同一命令可续跑已完成步骤，不自动删除部分安装。安装错误不会打印可能包含凭据的包管理器原始输出；先检查网络、基础工具和可用Python版本，再由用户在本机诊断具体安装步骤。
