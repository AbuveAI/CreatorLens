# 0.1.0a2 发布与课程版本

公共仓库：[AbuveAI/CreatorLens](https://github.com/AbuveAI/CreatorLens)。

0.1.0a2 作为首个公开Alpha源码版本供独立目录测试；完整真实研究与可选云服务仍待验收，暂不作为稳定版本发布。

## 后续稳定版发布前

- 按 fresh-validation.md 完成离线、新环境安装和真实混合样本验收；云服务未测试就明确标注可选适配的验证范围。
- 在完整依赖环境运行全部测试，不把缺依赖导致的跳过当作通过。
- `package` 仅从 `release-files.json` 导出文件。新文件必须经检查后显式加入，不递归压缩整个项目。
- 检查清单、内容、Git工作区和历史；不含本机路径、密钥、会话、真实创作者资料、第三方源码和环境。白名单和基础扫描不是密钥审计的完全替代品。
- 自有代码MIT，保留上游归属与现状说明。不要把CreatorLens的许可证当作上游或平台内容的授权。
- README、版本号、CHANGELOG与实际支持能力一致；用户确认真实测试结果后再发布。

## GitHub介绍草案

仓库描述：Agent协作的创作者内容研究工具：纯接口采集、图文与视频混合取样、可追溯分析和本地报告。

Topics候选：creator-tools、content-research、agent、xiaohongshu、python。

首版说明重点：小红书Spider_XHS接口；用户自有登录与环境；Agent负责语义阅读和分析；本地成果优先；可选ASR与飞书；多平台尚未实现。不要写“全自动运营”“支持全平台”或“无限采集”。

## 社群介绍草案

CreatorLens 是一个面向已在使用 Agent 的内容创作者的开源研究工具。把目标账号交给自己的 Agent，它可以协助整理公开作品、阅读图文、校订视频转写，把结论和证据放进本地报告。第一版从小红书开始，底层使用Spider_XHS接口，后续再扩展平台。当前先开放测试版，欢迎反馈安装、采集恢复和报告质量问题。

## 课程对应

课程演示注明CreatorLens版本、上游固定提交和演示环境。公开演示用 `demo` 或已获公开授权的脱敏案例；个人工作区与账号配置不随课程资料分发。学生从仓库标签或发行包开始，不照搬维护者本机路径。后续课程更新通过版本说明说明变化。
