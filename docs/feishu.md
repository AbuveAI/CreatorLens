# 飞书作为可选增强

本地报告是完整交付，飞书不作为安装或研究的必选依赖。项目不附带飞书CLI、应用密钥、维护者的Base ID或表结构，也不自动创建云端资源。

`feishu-plan --task ...` 在本地报告验收后生成 `exports/feishu-plan.json`，包含每件作品的稳定键、文字、评论、研究摘要、封面和全部图文原图清单。原始API响应和视频不进入上传清单。该命令不会写入飞书，`feishu.enabled` 是用户的意愿配置，不构成执行授权。

首版采用 **Agent执行同步**：让具备飞书能力的 Agent 读取计划并使用用户已安装的飞书工具。没有自动通用 `sync` 命令，也没有假设任意Base的字段均兼容。

操作顺序：

1. 按本次用户授权确认目标Base/文档、身份和权限；读取真实表结构。缺目标时先询问目标，不猜测或借用维护者资源。
2. 将稳定键 `platform:account:batch:work` 映射到可查询字段。更新旧批次统计范围时先检查原有研究样本，不把不同批次混为一条。
3. 先按稳定键查重，再写文字；保存返回的记录ID和请求状态。写入不确定先查询，禁止直接再次创建。
4. 封面逐作品定向上传；图文全部原图按01起排序。图文描述明确是逐图观察与分析，OCR另列。视频只保存在本地，不上传视频附件；原图与封面可各占对应字段。
5. 用记录ID回读文字、封面和原图数量/顺序及附件标识；必要时下载核对内容。报告以可读文档或用户授权方式保存，不能将本机文件路径冒充可分享的云端链接。
6. 把实际目标、字段映射、记录ID、请求不确定项、附件摘要与回读结果记到批次 `exports/feishu-sync-receipt.json`。全部回读后才声明云端完成。

使用 lark-cli 的 Agent 应先读取其自身提供的当前飞书技能与命令帮助，显式选择用户授权的身份，按现有权限处理；不要把本项目文档当作发送消息或操作其他资源的授权。当前适配只交付计划，云端验收必须由实际执行该步骤的 Agent 完成。
