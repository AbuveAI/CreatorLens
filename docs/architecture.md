# 架构与目录

## 三个位置

- 旧工程：原位保留历史代码与真实资料，作为受控迁移来源。
- `creatorlens/`：唯一公共核心；公共代码、模板、测试、说明和 Agent 研究规范。
- `creatorlens-workspace/`：维护者或用户自己的配置、会话、任务、素材和研究成果。

后两者通常同级，但用户可以选择其他位置。工作区不可位于源码内，也不可作为源码的上级目录。
这一限制避免误把工作资料纳入源码发布和模糊数据归属。程序校验真实路径，包含符号链接目标。

## 公共仓库

```text
creatorlens/
  creatorlens/       Python 包（任务、采集、外部适配、会话与本地验收）
  configs/           公共配置模板
  docs/              产品边界、架构、迁移与发布说明
  tests/             隔离环境测试
  AGENTS.md          Agent 接手入口
  pyproject.toml     本地包声明
```

skills/creatorlens/ 提供项目内Agent入口；demo.py生成自制演示，不携带真实样本。

## 工作区

```text
creatorlens-workspace/
  config/settings.json     用户设置；只存服务凭据位置或环境变量名称
  dependencies/Spider_XHS/  外部源码及独立.venv
  private/                 接口登录会话等敏感状态
  profiles/                私人研究偏好与模板
  data/                    平台 / 账号 ID / 批次及素材、审阅、检查点
  reports/                 报告入口、导出及维护者本地验收
  tmp/                     可归档后清理的临时内容
```

正式研究报告以批次内版本为事实来源，reports/ 用作索引或导出；避免两份报告各自编辑。
init-workspace 只建立工作区；init 创建独立研究批次。

## 处理分层

1. **平台接入**：Spider_XHS 外部运行环境负责接口调用；CreatorLens 负责范围与请求控制、字段转换、媒体保存和采集证据。
2. **通用处理**：任务、批次、媒体类型、文件摘要、转写适配、状态、续跑和验证。
3. **Agent 研究**：校订、逐图描述、证据关联、账号与内容研究、创作启发。
4. **输出适配**：本地报告为核心，飞书等为可选出口。

账号身份由 platform + account_id 确定；作品由 platform + work_id 确定。
任务记录代码版本、样本范围和各阶段证据；ASR提交检查点记录本次授权时间。实际用户授权以上下文为准，服务配置与凭据不复制进任务。
平台原始字段与统一字段分别保存，未知值不能伪造为零。

## 配置与环境

`--workspace` 优先于 `CREATORLENS_WORKSPACE`，二者都缺少时明确提示。
Spider_XHS 源码目录与 Python 解释器配置为绝对路径，外部依赖不位于公共仓库中。
Python 虚拟环境解释器保留符号链接路径，不能 resolve 后误用基础解释器。
诊断仅检查本机文件和工具位置，不执行上游代码、不验证登录和云端权限。

会话锁已按工作区隔离，任务锁按批次隔离；遇忙碌立即停止提示，不另开二维码。
ASR和报告复用批次写锁；依赖安装使用工作区安装锁。
旧会话不自动迁移或重建；在明确迁移与兼容验证前，新旧工程不可共享写入同一状态。

## 当前接口核心模块

- tasks.py / storage.py：外置任务、原子落盘、文件摘要与单写者锁。
- dependency.py：外部源码指纹与显式版本更新；由setup.py显式安装固定提交，不自动更新。
- spider.py / worker.py：独立 Python 运行环境、会话校验、请求间隔、停止策略及接口字段适配。
- session.py：只存本工具接口签发的会话；不读取真实浏览器状态。
- collection.py：完整列表归位、混合取样、原图/视频保存、评论样本与本地材料验收。

上游类名 BrowserHttpClient 是其 HTTP 传输类，不是浏览器自动化。CreatorLens 不启动或连接浏览器。

## 研究与交付模块

- setup.py：外置依赖安装、阶段续跑及固定提交核验。
- asr.py：可选云端转写，提交前保存ID，不确定状态只查询；原稿留存。
- research.py：来源绑定、逐段/逐图审阅协议、证据引用和本地报告。
- feishu.py：仅生成可选云端交接计划；云端映射、写入与回读由Agent完成。
- demo.py：自制图文离线演示，与真实采集任务隔离。
- release.py：精确白名单导出公共源码。

当前任务协议显式限定xiaohongshu，尚不声称平台无关。扩展平台时先增加统一协议与适配测试，不把新平台伪装成小红书ID。
